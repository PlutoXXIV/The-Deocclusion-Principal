## Directions to Run this

Using conda, clone my environment using the environment.yml file

> conda env create -f environment.yml

and then run app.py
 source your env, go to the project directory and run

> python app.py

you can upload any satellite image having road network. you can use the given sample image form the IO folder
or
you can download the dataset on which the model was trained from here -->

https://www.kaggle.com/datasets/balraj98/deepglobe-road-extraction-dataset
